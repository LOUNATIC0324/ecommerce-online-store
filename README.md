# Green Basket

A modern fruits and vegetables storefront built with Next.js and Tailwind.

## Stack
- Next.js
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes
This project is a starter storefront for a fresh produce shop. You can extend it with:
- product detail pages
- shopping cart
- checkout flow
- admin dashboard
- authentication
- database and Stripe integration
